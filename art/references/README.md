# Pirate art references

User-provided reference images, collected September 21, 2026. Original JPEGs are
preserved without resizing or recompression. These are visual direction, not
runtime textures; `.gdignore` keeps them out of Godot's asset importer.

## Approved direction

The selected rendering style is **option 1, Toon / Cel-Shaded**, in the character
comparison: flat lighting bands, hard shadows, minimal texture detail, optional
outlines. The T-pose image defines the main character's design and proportions.

Environment direction: broad readable silhouettes, faceted rocks/cliffs, grouped
tropical foliage, curved palms, warm sand, darker wet sand, turquoise shallows,
broken shoreline foam, and clear cast shadows. Use the final terrain/water sheet
for gameplay-camera scale and material transitions.
